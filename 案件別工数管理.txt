================================================================================
  1. このシステムでできること
================================================================================

本システムは、士業・コンサルティング・制作会社など「案件単位で
仕事を進める企業」向けの工数・収益管理システムです。

Google スプレッドシートをデータベースとして使い、Webアプリから
直感的に操作できます。

■ 主な機能
  ・案件ごとの工数（作業時間）を記録・集計
  ・スタッフの稼働状況をリアルタイムで把握
  ・案件の収益性（粗利益・粗利率）を自動計算
  ・経費の登録と請求書データの管理
  ・見積精度の分析と稼働予測
  ・月次・顧客別・案件別のレポート自動生成

================================================================================
  3. 基本操作の流れ
================================================================================

初めて使うときは、以下の順番で進めてください。

  ステップ1: マスタデータの登録
  ─────────────────
    まず「マスタ」メニューから基本情報を登録します。
    ① 顧客マスタ    → 取引先の企業・個人を登録
    ② スタッフマスタ  → 自社のメンバーを登録
    ③ 案件種別マスタ  → 仕事の種類を登録（例: 決算申告、顧問契約）

  ステップ2: 案件の登録
  ─────────────────
    「案件管理」から新しい案件（仕事）を登録します。
    顧客・担当者・金額・期限などを設定します。

  ステップ3: 日々の工数入力
  ─────────────────
    毎日の作業時間を「工数入力」から記録します。
    どの案件に何時間使ったかを入力します。

  ステップ4: レポートで確認
  ─────────────────
    「レポート」や「ダッシュボード」で
    案件の進捗・収益性・スタッフの稼働状況を確認します。


================================================================================
  4. 各機能の使い方
================================================================================

────────────────────────────────────
  4-1. ダッシュボード
────────────────────────────────────

  ■ 概要
    システム全体の概況を一目で確認できるトップページです。

  ■ 表示内容
    ・進行中の案件数 / 全案件数
    ・今月の総稼働時間
    ・予算超過・警告が出ている案件の一覧
    ・直近6ヶ月の月次サマリー

  ■ 使い方
    ログイン後、最初に表示されるページです。
    毎朝の業務開始時にチェックすることで、
    注意が必要な案件をすぐに把握できます。

  ■ アラートの見方
    ・「予算超過」（赤）: 見積工数を超過しています。即対応が必要。
    ・「警告」（黄）: 見積工数の80%以上を消化。注意してください。


────────────────────────────────────
  4-2. 工数入力
────────────────────────────────────

  ■ 概要
    日々の作業時間を記録する、最も頻繁に使う画面です。

  ■ 入力方法

    【個別入力】
    1. 「+ 新規」ボタンをクリック
    2. 以下の項目を入力:
       ・記録日      → 作業した日付（デフォルトは今日）
       ・スタッフ    → 自分の名前を選択
       ・案件        → 作業した案件を選択
       ・作業項目    → 行った作業の種類を選択
       ・開始時刻    → 作業開始時刻
       ・終了時刻    → 作業終了時刻
       ・作業時間（分）→ 時刻入力の代わりに分数で直接入力も可
       ・請求区分    → 「請求対象」「内部」「サービス」から選択
       ・作業内容    → 具体的な作業メモ
    3. 「保存」をクリック

    【一括入力】
    1. 「一括入力」タブをクリック
    2. スタッフと記録日を選択
    3. 複数の作業を一度にまとめて入力
    4. 「一括登録」をクリック

    【タイマー機能】
    1. 「タイマー」タブをクリック
    2. 案件と作業項目を選択
    3. 「開始」ボタンで計測スタート
    4. 作業終了時に「停止」→ 自動で時間が計算されます

  ■ 請求区分の意味
    ・請求対象  → 顧客に請求できる作業時間
    ・内部      → 社内ミーティングなど請求対象外の作業
    ・サービス  → 顧客へのサービス（無料提供）の作業

  ■ 履歴の確認
    「履歴」タブで過去の工数記録を検索・確認できます。
    スタッフ、案件、日付範囲で絞り込みが可能です。

  ※ 自動計算される項目:
    ・作業時間（時間換算）
    ・原価金額 = スタッフの原価単価 × 作業時間
    ・請求金額 = スタッフの請求単価 × 作業時間


────────────────────────────────────
  4-3. 案件管理
────────────────────────────────────

  ■ 概要
    受注した案件（仕事）の情報を管理します。

  ■ 案件一覧
    ・ステータスで絞り込み可能（進行中 / 見積中 / 完了 など）
    ・デフォルトでは「進行中」の案件が表示されます
    ・案件名をクリックすると編集画面が開きます

  ■ 新規案件の登録
    1. 「+ 新規」ボタンをクリック
    2. 必須項目:
       ・案件名  → 案件の名前（例:「○○株式会社 決算申告」）
       ・顧客    → 顧客マスタから選択
    3. 推奨項目:
       ・案件種別    → 仕事の種類
       ・契約形態    → スポット / 顧問 / タイムチャージ / 固定
       ・主担当      → 担当スタッフ
       ・契約金額    → 請求予定額
       ・見積工数    → 想定される作業時間（時間）
       ・納期・期限  → 完了予定日
    4. 「保存」をクリック

  ■ ステータスの意味
    ・見積中  → まだ受注していない段階
    ・進行中  → 作業中の案件
    ・完了    → 作業が終わった案件
    ・請求済  → 請求書を発行した案件
    ・入金済  → 入金が確認された案件
    ・中止    → キャンセルされた案件

  ■ ポイント
    「契約金額」と「見積工数」を登録しておくと、
    工数の消化率や粗利益が自動計算されるようになります。
    できるだけ正確に入力してください。


────────────────────────────────────
  4-4. 顧客マスタ
────────────────────────────────────

  ■ 概要
    取引先の情報を管理します。

  ■ 登録項目
    ・顧客名（必須）、カナ
    ・法人 / 個人 区分
    ・業種
    ・代表者名、担当者名
    ・電話番号、メールアドレス、住所
    ・顧客ランク（A / B / C）
    ・支払条件（翌月末 / 翌々月末 など）
    ・請求締日（末日 / 15日 / 20日 / 25日）
    ・ステータス（取引中 / 休止 / 解約）

  ■ 顧客ランクの目安
    ・A → 主要取引先（売上貢献度が高い）
    ・B → 通常の取引先
    ・C → 小規模または新規の取引先

  ■ 操作方法
    ・「+ 新規」で新規登録
    ・一覧の行をクリックして編集


────────────────────────────────────
  4-5. スタッフマスタ
────────────────────────────────────

  ■ 概要
    自社メンバーの情報と単価を管理します。

  ■ 重要な登録項目
    ・氏名（必須）
    ・役職（代表 / パートナー / マネージャー / スタッフ / アシスタント）
    ・職種（税理士 / 公認会計士 / エンジニア など）
    ・標準時給単価（原価）→ その人の時間あたりコスト
    ・標準請求単価（売価）→ 顧客に請求する時間単価
    ・月間標準稼働時間    → 1ヶ月の稼働可能時間（通常160時間）
    ・稼働率目標          → 目標とする稼働率（通常0.80 = 80%）

  ■ 単価設定のポイント
    原価単価と請求単価の設定が、収益性分析の基礎になります。

    例: スタッフAの場合
      原価単価: 3,000円/時間（人件費ベース）
      請求単価: 8,000円/時間（顧客への請求ベース）
      → 粗利: 5,000円/時間

    工数を登録すると、これらの単価から自動で
    原価金額と請求金額が計算されます。


────────────────────────────────────
  4-6. 案件種別マスタ
────────────────────────────────────

  ■ 概要
    案件の種類ごとのテンプレート情報を管理します。

  ■ 登録項目
    ・種別名（例: 法人決算申告、個人確定申告、顧問契約、相続税申告）
    ・カテゴリ大（例: 税務、法務、コンサル）
    ・標準工数（時間）→ この種別の案件にかかる標準的な作業時間
    ・標準単価        → この種別の標準的な請求額
    ・難易度（1〜5）

  ■ 活用方法
    案件種別ごとに標準工数を設定しておくと、
    「見積精度分析」で実績との乖離を分析できます。
    新規案件の見積もり精度向上に役立ちます。


────────────────────────────────────
  4-7. 経費管理
────────────────────────────────────

  ■ 概要
    案件に関連する経費を記録します。

  ■ 登録方法
    1. 「+ 新規」をクリック
    2. 入力項目:
       ・発生日
       ・スタッフ    → 経費を使ったスタッフ
       ・案件        → 関連する案件
       ・経費種別    → 交通費 / 宿泊費 / 印紙代 / 登録免許税 /
                       外注費 / 通信費 / 消耗品費 / その他
       ・金額
       ・請求区分    → 実費請求 / 含む / 自社負担
       ・内容        → 経費の具体的な内容
       ・領収書      → 有 / 無
       ・承認状態    → 申請中 / 承認 / 却下
    3. 「保存」をクリック

  ■ 請求区分の意味
    ・実費請求  → 顧客に実費で請求する経費
    ・含む      → 案件の報酬に含まれている経費
    ・自社負担  → 会社が負担する経費（請求しない）

  ※ 「実費請求」かつ「承認済み」の経費は、
    請求書の自動計算に含まれます。


────────────────────────────────────
  4-8. 請求管理
────────────────────────────────────

  ■ 概要
    請求書データを作成・管理します。

  ■ 請求書の作成方法
    1. 「+ 新規請求」をクリック
    2. 顧客・案件・請求日を選択
    3. 請求期間（FROM / TO）を設定
    4. 「自動計算」ボタンをクリック
       → 工数データと経費データから以下が自動入力されます:
         ・基本報酬（固定 / スポット契約の場合、契約金額）
         ・タイムチャージ金額（請求対象の工数 × 請求単価）
         ・実費金額（承認済みの実費請求経費の合計）
    5. 必要に応じて金額を調整
    6. 支払期限、ステータスを設定
    7. 「保存」をクリック

  ■ 請求ステータス
    ・下書き    → 作成中（まだ発行していない）
    ・発行済    → 請求書を発行した
    ・入金済    → 全額入金確認済み
    ・一部入金  → 一部のみ入金あり
    ・遅延      → 支払期限を過ぎている

  ※ 請求番号は「INV-202602-001」のように自動生成されます。
  ※ 消費税は設定の税率（デフォルト10%）で自動計算されます。


────────────────────────────────────
  4-9. レポート（4種類）
────────────────────────────────────

  ■ 案件別レポート
    案件ごとの収益性を一覧表示します。

    表示項目:
    ・案件名、顧客名
    ・契約金額
    ・実績工数（何時間使ったか）
    ・工数消化率（見積工数に対する進捗）
    ・総原価（人件費 + 経費）
    ・粗利益 / 粗利益率
    ・予算消化アラート

    見方のポイント:
    ・粗利益率が50%以上 → 緑色（収益性が高い）
    ・粗利益率が30%未満 → 赤色（要注意）
    ・消化率80%以上      → 黄色警告
    ・消化率100%以上     → 赤色（予算超過）

  ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─

  ■ スタッフ別レポート
    スタッフごとの稼働状況を月別で確認します。

    表示項目:
    ・氏名、役職
    ・総稼働時間
    ・請求対象時間（顧客に請求できる稼働）
    ・稼働率（稼働時間 ÷ 標準稼働時間）
    ・稼働率達成度（稼働率 ÷ 目標稼働率）
    ・担当案件数
    ・売上貢献額

    見方のポイント:
    ・稼働率100%以上 → 赤色（過負荷。業務量を調整してください）
    ・稼働率70%未満  → 黄色（余裕あり。案件の割り当てを検討）

    ※ 右上の月選択で対象月を変更できます。

  ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─

  ■ 月次レポート
    月ごとの経営数値の推移を確認します。

    表示項目:
    ・売上合計、前月比
    ・総原価（人件費 + 経費）
    ・粗利益 / 粗利益率
    ・完了案件数、新規受注数
    ・全体稼働率

    見方のポイント:
    ・月ごとの売上推移を見て、繁閑の傾向を把握
    ・粗利益率の変動を追って、価格設定の妥当性を確認
    ・新規受注数で営業活動の成果を把握

  ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─

  ■ 顧客別レポート
    顧客ごとの収益性を月別で確認します。

    表示項目:
    ・顧客名、案件数
    ・売上合計、工数合計
    ・粗利益 / 粗利益率
    ・顧客ランク
    ・収益性評価（高 / 中 / 低 / 赤字）

    見方のポイント:
    ・収益性が「赤字」の顧客 → 価格交渉や業務効率化を検討
    ・収益性が「高」の顧客   → 良好な関係を維持


────────────────────────────────────
  4-10. 分析（2種類）
────────────────────────────────────

  ■ 見積精度分析
    完了した案件の「見積もりと実績の差」を分析します。

    表示項目:
    ・案件名、案件種別
    ・見積工数 vs 実績工数
    ・乖離率（実績がどれだけズレたか）
    ・精度評価（高 / 中 / 低）
    ・次回見積への改善提案

    見方のポイント:
    ・乖離率が +20% 以上 → 見積もりが甘い（次回は工数を増やす）
    ・乖離率が -20% 以下 → 見積もりが大きすぎた（次回は減らす）
    ・案件種別ごとの傾向を見て、見積もりの精度を向上させましょう

  ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─

  ■ 稼働予測
    今月と来月のスタッフ別の稼働見込みを表示します。

    表示項目:
    ・対象年月、スタッフ名
    ・月間稼働可能時間
    ・確定案件の工数
    ・予測稼働時間
    ・予測稼働率
    ・空き時間
    ・アラート（過負荷 / 適正 / 余裕）

    見方のポイント:
    ・「過負荷」のスタッフ → 案件の再配分や納期調整を検討
    ・「余裕」のスタッフ   → 新規案件の割り当て候補


────────────────────────────────────
  4-11. 設定
────────────────────────────────────

  ■ 概要
    システム全体の設定と手動集計の実行ができます。

  ■ 手動集計ボタン
    通常は自動で集計されますが、すぐにデータを更新したい場合は
    以下のボタンで手動実行できます。

    ・案件別集計を実行  → 全進行中案件の工数・収益を再集計
    ・月次集計を実行    → 先月の月次サマリーを再集計
    ・スタッフ別集計    → 先月のスタッフ稼働データを再集計
    ・見積精度分析      → 完了案件の見積精度を再分析

  ■ スプレッドシート側の設定項目（設定_システム設定シート）
    ・消費税率          → 請求書の消費税計算に使用（デフォルト: 0.10）
    ・最小入力単位（分）→ 工数入力の最小単位（デフォルト: 15分）
    ・各種アラート閾値  → 警告を出す基準値
    ・請求番号プレフィックス → 請求番号の先頭文字（デフォルト: INV）
    ・アラート通知先メール   → 予算超過時の通知送信先


================================================================================
  5. 日常業務での使い方（運用フロー）
================================================================================

■ 毎日やること
──────────────────────
  朝:  ダッシュボードでアラート確認
  日中: 作業ごとに工数を入力（タイマー機能も活用）
  夕方: 当日の工数入力漏れがないか確認

■ 案件の受注時
──────────────────────
  1. 顧客が未登録なら「顧客マスタ」に追加
  2. 「案件管理」→「+ 新規」で案件を登録
     ※ 契約金額・見積工数を必ず入力

■ 案件の完了時
──────────────────────
  1. 「案件管理」で案件のステータスを「完了」に変更
  2. 「経費管理」で未登録の経費がないか確認
  3. 「請求管理」で請求書データを作成
     → 「自動計算」で金額を算出 → 確認して保存
  4. 入金確認後、請求ステータスを「入金済」に変更

■ 月末・月初にやること
──────────────────────
  ・「設定」→「月次集計を実行」「スタッフ別集計」を実行
  ・「月次レポート」で先月の実績を確認
  ・「スタッフ別レポート」で稼働率を確認
  ・「稼働予測」で来月の負荷を確認し、人員配置を検討

■ 四半期・年次
──────────────────────
  ・「見積精度分析」で見積もりの傾向を確認
  ・「顧客別レポート」で顧客ごとの収益性を評価
  ・単価の見直しやサービス改善の参考にする


================================================================================
  6. 企業にとってのメリット
================================================================================

■ 1. 案件の赤字を未然に防止
──────────────────────────
  工数の消化率をリアルタイムで把握できるため、
  予算超過になる前にアラートが出ます。
  「気づいたら赤字だった」を防ぎます。

  例: 見積20時間の案件で16時間消化 → 黄色警告
      → 残り工数を意識して効率的に作業を進められる

■ 2. 正確な収益管理
──────────────────────────
  案件ごとの粗利益・粗利率が自動計算されます。
  「忙しいのに利益が出ない」原因を特定できます。

  例: A社の案件は粗利率60%、B社は15%
      → B社の案件は単価交渉または工数削減が必要

■ 3. スタッフの適正配置
──────────────────────────
  スタッフごとの稼働率と稼働予測が可視化されます。
  特定の人に業務が集中する問題を早期発見できます。

  例: Aさん稼働率120%（過負荷）、Bさん50%（余裕）
      → Bさんに案件を振り分けて負荷を平準化

■ 4. 見積もり精度の継続的な向上
──────────────────────────
  過去の案件の「見積もり vs 実績」を蓄積・分析。
  案件種別ごとの傾向がわかり、次の見積もりに活かせます。

  例: 「相続税申告」は平均して見積もりの1.3倍かかる
      → 次回から見積工数を30%増やして提案

■ 5. 経営判断のスピードアップ
──────────────────────────
  月次レポート・顧客別レポートで経営数値が自動集計。
  売上推移、顧客別の収益性、全体の稼働率など、
  経営に必要な数値がすぐに確認できます。

■ 6. 請求漏れの防止
──────────────────────────
  工数データと経費データから請求金額を自動計算。
  「この作業の請求を忘れていた」を防ぎます。


================================================================================
  7. よくある質問（FAQ）
================================================================================

Q. 工数の入力を忘れた場合はどうすればいいですか？
A. 「工数入力」画面で記録日を過去の日付に変更して入力できます。
   履歴タブから過去の記録を編集・削除することも可能です。

Q. 間違って登録したデータを修正したい場合は？
A. 各一覧画面で該当の行をクリックすると編集画面が開きます。
   内容を修正して「保存」してください。

Q. レポートのデータが古い場合は？
A. 「設定」画面から手動集計ボタンを押してください。
   集計データが最新の工数・経費データで再計算されます。

Q. 複数のスタッフが同時に使えますか？
A. はい。Webアプリなので複数人が同時にアクセスして
   工数入力やデータ確認ができます。

Q. スマートフォンからも使えますか？
A. はい。ブラウザからWebアプリのURLにアクセスすれば
   スマートフォンでも利用できます。
   左上の「≡」ボタンでメニューを開閉できます。

Q. スプレッドシートを直接編集してもいいですか？
A. 基本的にはWebアプリ経由での操作を推奨します。
   スプレッドシートを直接編集すると、データの整合性が
   崩れる可能性があります。ただし、データの確認や
   一括修正が必要な場合はスプレッドシートも活用できます。

Q. 消費税率が変更された場合は？
A. スプレッドシートの「設定_システム設定」シートで
   「消費税率」の設定値を変更してください。
   例: 10% → 0.10、8% → 0.08

Q. データのバックアップは必要ですか？
A. Google スプレッドシートは自動保存・バージョン管理されますが、
   定期的にスプレッドシートのコピーを作成しておくと安心です。
   （スプレッドシートの「ファイル」→「コピーを作成」）
